# Coordinator seeds

Tracked Twin-overlay defaults for backends that have **no** local `lab_view_path`
(HTTP-edge real benches). Copied into `coordinator_data/<backend_id>/` on first
create via `coordinator_seed_path` in `schemas/backends.json`.

Laser lines are Twin-only overlays (not edge layout). Geometry here matches the
historical real communicator bundle on `refactor2`
(`backend/lab_communicator/real/lab_view/default/laser_lines.json`).
